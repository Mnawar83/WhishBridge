# Before buying WhishBridge Developer Kit

**Release:** v0.2.1 Beta. Commercial source code is delivered via Payhip with a one-project license.

## Good fit
- You are a Node.js backend developer building a provider-approved cross-domain payment flow for a business.
- You can run Node.js 22+ on a persistent server with durable SQLite storage and HTTPS.
- You can integrate your own authenticated order and entitlement system.
- You want source code, reference patterns and an offline test suite, not a hosted gateway.

## Not a good fit
- You need a ready-made Shopify, WooCommerce, WordPress or Laravel plugin.
- You only deploy to serverless ephemeral disks with no database adaptation.
- You expect included Whish credentials, merchant authorization, refunds/dispute handling or a guarantee of automatic mobile redirects.
- You require production certification or documented live end-to-end settlement evidence.

## Included
- Node.js merchant API, per-site authentication, fixed server-side pricing and checkout idempotency.
- Persistent orders, provider verification, periodic reconciliation and signed event delivery.
- Receiving-site example with server-side entitlements.
- English and Arabic setup documentation and simulated-provider offline tests.
